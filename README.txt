UTTAR UNLOCKED WEBSITE

Files:
- index.html: website content and sections
- style.css: navy blue and royal gold design
- script.js: mobile navigation, trip form demo, newsletter demo, reveal animations

HOW TO USE:
1. Extract this ZIP into a folder.
2. Keep all three code files together in the same folder.
3. Open index.html in a browser, or open the folder in VS Code and use Live Server.
4. Images and Google Fonts currently load from online sources, so an internet connection is needed.
5. Some image providers may change or block direct image URLs. Replace any broken image URL in index.html with a photo you have permission to use.

NOTE:
Trip planner and newsletter are front-end demos only. They do not save bookings or send emails to a server.
